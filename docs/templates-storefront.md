# Lanespire Templates — 一覧 / Matching 専用ページ

更新：2026-09-15。PR #18の第2版。商品アプリではなく、販売紹介サイトです。

## ページ構成

- `/templates/`：システムテンプレートシリーズの入口。価値、第一弾Matchingのカード、導入支援、シリーズ共通FAQ。カードから `/templates/matching/` へ遷移します。
- `/templates/matching/`：Matching専用。仕様、納品範囲、恋活/婚活とカラー/画面の切替、料金、OEMの変更境界、FAQ。パンくず・ヘッダー・フッターから一覧へ戻れます。

両ページは `static/templates/` 配下の静的HTMLです。既存SvelteKitのstatic出力を利用します。`/`、`/mvp`、`/launch-lp`、Netlify Forms、DNS・ホスト設定は変更しません。末尾スラッシュを正規URLとしてリンクを統一しています。スラッシュなしはホストのディレクトリーindex解決も確認対象です。

## ビジュアルと画像

既存のLanespire Templatesのアイボリー・セージ・インク色を継承し、一覧はシリーズ全体、専用ページは商品UIを主役にします。共通CSSは `store.css` と `native.css`、ページ差分は `pages-v2.css` です。

全7種のビジュアルをローカルSVGプレースホルダーに変更しました。生成画像・写真はまだありません。`data-asset` と `media/manifest.json` で利用箇所を管理します。既存の人物イラストは除去しました。ロゴ・線画アイコン・HTMLのUI・数字は画像化せず維持します。

**生成プロンプトと差し替え方法： [templates-image-prompts.md](./templates-image-prompts.md)**

画像上のIDガイドは交換時に除去します。生成後も、画像はコンセプト、プロフィールは架空、支援写真はイメージと説明し、実機画面・実会員・導入実績として扱いません。

## 動きと操作

追加のブラウザーJavaScriptや外部依存はありません。CSSとradio/checkbox/details/popoverを利用します。

- モジュール・スマートフォン・画像カードの穏やかな浮遊とホバー。
- 対応ブラウザーでのページView Transition、スクロール連動の控えめな出現。
- 恋活は写真カード、婚活は結婚意向・生活観が読める一覧。見た目だけでなく情報順序を変えます。
- 3色、発見/会話/管理画面、恋活の2プロフィール、お気に入り表示、マッチ演出を切り替えます。
- チャットと運営管理は表示デモです。送受信・永続化・実会員の操作はありません。
- `prefers-reduced-motion` と明示的な「動きを抑える」を用意。本文はアニメーションに対応しない環境でも表示します。

## 確認

ローカルのChromiumで両ページを320/360/390/768/1024/1440/1920pxで描画し、横はみ出しなし。390/1440pxでプリセット、色、画面、プロフィール、マッチ/ライセンスpopover、Escape、動き停止を確認しました。HTML内のID重複、ページ内アンカー、画像ファイルとalt・寸法を確認しています。

ローカル環境の外部ネットワークとfileナビゲーションに制約があるため、ローカル確認は実ファイルのCSSと画像をインライン化して描画しました。ホスト上のナビゲーション確認とは分けます。CIの `scripts/qa-templates.py` は実ビルドをHTTPで開き、両ページ間の遷移と画像読み込みも検査します。CIの実施結果はPRで確認してください。
