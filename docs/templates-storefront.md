- `/templates/`：システムテンプレート販売シリーズの入口。第一弾Matching、ソース納品の価値、導入支援、シリーズ共通FAQ。

2ページの導線、既存の `/`・`/mvp`・`/launch-lp`、Netlify Forms・DNS・ホスト設定は維持します。静的HTMLをSvelteKitのstatic出力から配信します。PRプレビューで確認し、本変更ではmasterにマージしません。

## 第3版の設計

「開発の土台は、買う。独自の価値から、つくる。」をシリーズの主張とし、第一弾の商品価格と導入全体の費用を分けて伝えます。濃いインク色と淡いライムを入口の印象に使い、本文・比較・仕様は明るい背景で読める構成です。章番号で物語を説明せず、認識できるApp・API・Adminの奥行きと状態変化で、パッケージの内容を理解できるようにします。

- カタログ：HTMLの3層パッケージ。すべて/App/API/Adminで前面のレイヤーと説明が切り替わります。矢印・Home/Endでも操作可能。
- Matching：商品価格、会員アプリ・管理画面・コードの構成。写真中心の恋活と情報中心の婚活を切り替える既存デモを維持。
- ブランド名：入力した文字だけを画面と設定例に反映。textContentを使用しHTMLを実行せず、保存・外部送信をしません。
- コスト比較：下記の計算契約。プランの選択に応じ料金カードも強調。
- 動き：導入時のレイヤー組み立て、必要な選択切替、短い数字の更新。スクロールを横取りしません。OSのreduced-motionと既存の停止スイッチを尊重。

追加ファイルは `experience.css` と `experience.js`。旧 `store.css`・`native.css`・`pages-v2.css` は維持。新しい外部ライブラリ、分析SDK、決済SDKは追加していません。JSなしでも本文、元のCSSデモ、料金、ライセンス、リンクは利用でき、新しい計算フォームはinertとして固定例を表示します。

## 初期費用比較の契約

- 入力：スクラッチ開発、追加開発・改修、選んだプランに含まれない導入・公開準備。単位は万円、0〜10,000、0.1万円刻み。0.1万円＝1,000円。
- テンプレート利用額＝予定ライセンス額＋追加開発・改修＋プラン外の導入・公開準備。
- 差額＝スクラッチ額−テンプレート利用額。負なら高くなると表示し、削減と表示しません。
- 割合＝差額÷スクラッチ額。分母0では算出しません。空欄・範囲外・非数値は無効とし、古い試算値を残さず「—」にします。
- 初期例は300万円対49.8万円、差250.2万円。**市場相場・確定見積・削減保証ではなく仮定の例**です。同等の機能・品質・公開範囲で比較する必要があります。
- Brand/Launchの支援作業と手入力費用の二重計上は利用者が調整する旨を表示。追加費用を無断でゼロに変更しません。
- 外部サービス料、ストア関連費、集客、有人運営、継続保守は双方の計算外。税別表示。
- コピーには前提・注意事項を同梱。Clipboardが使えない場合は読取専用テキスト欄を選択します。見積依頼・購入・課金・個人情報送信は行いません。

## 画像とデモ

C01・M01・S01の画像枠は、独自HTML/CSSによる商品構成・2ブランド・導入手順に置き換えました。画像待ちの空欄にはしません。これら3つのSVGと生成プロンプトは将来の差し替え用として保持します。現行の使用箇所はHTMLの `data-asset` を正とします。

M02〜M05は**前版の架空成人プロフィール用SVG仮素材**を維持。人物写真の生成は行っていません。会員数・チャット・管理画面は表示デモであり、実会員・実売上・実際の運営業務を意味しません。WebデモはReact Nativeアプリの実機検証結果ではありません。

[画像プロンプト・寸法・差し替え手順](./templates-image-prompts.md) を保持します。写真を入れる場合は、架空性・再配布条件を確認し、文字やボタンは画像化せずHTMLで保ちます。

## 検証と再現

ローカルでは、CSS・画像・JSを読み込んだ直接HTML描画で159項目を確認しました。320〜1920px、ブランド名・プリセット・管理画面、計算の正常/負値/0/空欄/上限、停止スイッチ、JS無効を含みます。ローカルのブラウザnavigationに環境制約があるため、**HTTP上のページ遷移・実ビルドの検証とは区別**しています。

CIでは既存 `qa-templates.py` を維持し、追加の `qa-templates-experience.py` を実ビルドのHTTPに対して実行します。結果JSONとスクリーンショットをartifactに収録。一般CI、Corporate回帰、Templates検査は別々の結果として報告します。失敗した既存検査を無効化しません。

```sh
npm run build
python -m http.server 8766 --directory build
# 別ターミナル。Python playwright/Chromiumのインストールが必要。
python scripts/qa-templates.py --base-url http://127.0.0.1:8766 --root build
python scripts/qa-templates-experience.py --base-url http://127.0.0.1:8766
```

出荷条件：商品側の実装・実機・外部接続試験、利用条件と価格、運営体制等の確定は別タスクです。このPRは注文受付システムや完成したマッチングアプリを納品するものではありません。
