作成日：2026-09-15。対象：システムテンプレートシリーズの販売紹介サイト。第一弾はマッチングアプリ。これは商品アプリの実装・出荷を意味しません。

## 配置と確認

公開パスは `/templates/`。`static/templates/index.html` と同じフォルダーのCSS 2ファイルを、既存のSvelteKit adapter-staticの出力へコピーする構成です。新しい依存・サーバー処理・ブラウザーJavaScriptは追加していません。既存の `/`、`/mvp`、`/launch-lp`、Netlify Formsとホスト設定は変更していません。

`npm run build` 後に `build/templates/index.html`、`build/templates/store.css`、`build/templates/native.css` を確認し、既存のプレビューサーバーで `/templates/` を開いてください。ホスティング側のディレクトリーindex解決はデプロイ時に別途確認します。商品詳細は同じページの `#included` に配置しており、未作成の `/templates/matching` へのリンクはありません。

## 見た目と操作

アイボリー・セージ・インク色、大きな日本語見出し、浮遊するアプリと管理画面、奥行きのある製品カード、濃色のブランド体験セクションを採用。人物は自作の架空SVGイラストで、実会員・実績・推薦ではありません。

ブラウザー標準のradio・select・details・popoverとCSSで、恋活/婚活、3色、発見/会話/管理画面、マッチ演出、FAQ、ライセンス説明、アニメーション停止を切り替えます。CSS :has() と Popover API を利用するため、対応するモダンブラウザーでの確認が必要です。prefers-reduced-motionを尊重します。

チャットは固定表示で、送信・保存・相手との通信はありません。管理画面も表示例で、審査処理は実行しません。スキップ・お気に入りは無効な表示例です。コスト比較は300万円と49.8万円の固定された仮定例であり、入力式シミュレーターではありません。差額250.2万円を市場実績や削減保証として扱いません。

初期のJavaScript案は接続ツールの安全確認で書き込みが拒否されたため、そのスクリプトもビルド用変換スクリプトも本PRへ入れていません。本PRは実行スクリプトを含まない静的版です。
