## 差し替え手順

1. 各画像をWebPに変換して、表に示したファイル名で `static/templates/media/` に追加します。横長は約200〜350KB以下、人物は約80〜180KB以下を目安に、見た目を確認して圧縮してください。無理な圧縮は不要です。
2. `static/templates/index.html` と `static/templates/matching/index.html` の、対象IDの `src="/templates/media/ID.svg"` を `src="/templates/media/ID.webp"` に変更します。同じIDはすべて変更します。
3. `media/manifest.json` の `src` を更新し、画像の実寸を確認します。HTMLのwidth/height、object-fit、object-positionも実画像に合わせて確認します。
4. 該当画像のaltから「差し替え用画像枠 ID」を外し、内容の説明に変更します。置換済みの画像上に重なる `.asset-id` のガイド表示を削除します。
5. 商品画像は「コンセプト」、人物は「架空プロフィール」、支援写真は「イメージ」と分かる説明を維持します。生成画像を実機画面・実会員・導入実績の証拠として扱いません。
6. 320px・390px・768px・1440pxで、顔のクロップ、文字との重なり、画像のはみ出しを確認してください。

画面UIを丸ごと画像にしないため、ブランドカラー切替・婚活一覧・恋活カードなどの操作は、人物画像を置き換えても維持できます。
